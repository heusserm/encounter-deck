# Contributing to EncounterDeck

Thanks for your interest in improving EncounterDeck! Bug reports, ideas, and pull
requests are all welcome.

## How to contribute

1. Open an issue to discuss anything substantial before you build it.
2. Fork, branch, make your change, and add/adjust tests where it makes sense
   (`./gradlew :engine:jvmTest :backend:test`).
3. Open a pull request describing what and why.
